## 아이디어 관리

아이디어는 각자 브랜치를 파서 `ideas/` 아래에 정리한다. 문서든 코드든 데이터 조사든 한 폴더에 모은다.

```bash
scripts/new-idea.sh breakwater-guard "방파제 보행자 위험 경보 에이전트"
```

`main`에서 `idea/NNN-<slug>` 브랜치를 파고 `ideas/NNN-<slug>/`에 템플릿을 복사한다.
자세한 규칙은 [ideas/README.md](ideas/README.md).

## 문서를 어디에 쓰나

**"이걸 PR에서 리뷰받아야 하나?"** 예면 레포, 아니면 노션.

- **노션** — 진행 상황 트래커, 회의록, 제출 서류 체크리스트, 팀원 정보
- **레포** — 결정([ADR](docs/decisions/)), 설계, API 스펙, 아이디어, 코드

한 사실은 한 곳에만 둔다. 두 번째 위치에는 링크만.
전체 규칙은 [0001 ADR](docs/decisions/0001-context-management.md).

# 해풍 웹앱 (본선 서비스)

덕장 운영자와 근로자를 위한 반응형 웹앱입니다. 관측은 E-UM 실제 자료, AI 설명은 OpenAI-호환 LLM(Groq 등)을 통해 제공합니다.

## 실행

Node.js **22.18 이상**을 사용합니다. `.env.example`을 참고해 무시되는 `.env.local`에 `EUM_SERVICE_KEY`, `OPENAI_API_KEY`를 설정합니다. 키는 브라우저용 `VITE_` 변수에 넣지 않습니다.

```bash
npm install
npm run dev
```

기본 주소: **http://127.0.0.1:3000**

```bash
npm test
npm run build
npm run preview
npm run format:check
```

개발·미리보기 서버 모두 로컬 API를 제공합니다. `dist/`만 정적 배포하면 API는 포함되지 않습니다.

## 사용자 흐름

1. **가입·로그인:** 이메일과 비밀번호로 계정을 만들고 이름을 등록합니다. 기존 세션으로 재방문하면 소속 덕장이 열립니다.
2. **덕장 운영자:** 이름·주소·지도 핀으로 실제 덕장을 등록합니다. 홈에서 관측값, 진행 중인 건조, 근로자 응답을 보고 필요한 작업 화면으로 이동합니다.
3. **근로자 초대:** 덕장·팀 관리에서 한국어 또는 베트남어 초대 링크를 생성합니다. 링크는 7일간 유효하고 한 사람이 수락할 수 있습니다. 사용자가 링크를 직접 전달합니다.
4. **근로자 참여:** 링크를 열고 가입 또는 로그인한 뒤 덕장 이름을 확인해 참여합니다. 개인 언어로 할 일을 확인하고 확인·질문·완료 보고를 남기고 운영자의 답변을 확인합니다.
5. **일상 작업:** 운영자가 건조 시작과 한국어 안내를 승인하면 팀에 공유됩니다. 근로자 응답은 갱신되며, 배치 종료는 운영자가 별도로 승인합니다.
6. **여러 덕장:** 소속 덕장을 전환하면 해당 덕장의 역할과 기록이 적용됩니다. 초대 취소, 근로자 제외, 위치 수정은 운영자만 할 수 있습니다.

초기 생산 기록은 비어 있습니다. 이전 시연 데이터는 실제 계정에 자동으로 가져오지 않습니다.

## 현재 구현

- **역할별 화면:** 운영자 홈·건조 기록·안내·팀 관리·AI 도우미, 근로자 한국어/베트남어 할 일·지난 안내·본인 응답.
- **US-1 관측:** 등록 위치와 관측소 거리 계산, 1km 내 최근 관측소 우선 선택, 직접 선택, 원천 시각·결측·과거 자료 표시. 검증된 건조 기준이 없으므로 적합 등급을 생성하지 않습니다.
- **US-2 기록:** 배치 시작·종료·취소 승인, 유효한 현재 관측의 수동 기록, 집계·내려받기. 덕장별 서버 저장과 충돌 재시도로 동시 응답을 보존합니다.
- **US-3 안내:** 승인된 한국어·준비된 베트남어 문안을 공유하고, 실제 가입 근로자의 확인·질문·완료와 운영자의 질문 답변을 기록합니다. 답변은 작성한 원문으로 전달됩니다. 근로자의 완료 보고가 배치를 종료하지 않습니다.
- **대기 경험:** 대기 단계를 표시하고 완성된 AI 답변을 한 번에 추가합니다. 중단·재시도, 요청 중 버튼 잠금, 오류·빈 상태, 동작 줄이기 설정을 지원합니다.

**2026-10-04 확인:** E-UM 관측소 목록·일괄·단건 API 모두 HTTP 200. 관측소 24개와 관측값 23행을 확인했습니다. [실제 호출 기록](research/api-tests/2026-10-04-eum-key.md). 조회 실패 시에만 보관된 과거 실측을 명시해 보여 주며 현재 값으로 바꾸지 않습니다.

## 저장과 백엔드 연결

계정·세션·덕장·초대·배치·안내는 Git과 정적 제공에서 제외한 `.local-data/workspace.json`에 저장합니다. 비밀번호는 scrypt 해시, 초대/세션 토큰은 해시로 보관하며 브라우저에는 HttpOnly 세션 쿠키를 사용합니다. 대화는 사용자·덕장별 브라우저 저장소에만 남습니다. 기록을 유지하려면 `.local-data/`를 보존하세요.

현재 서버는 **개발용 루프백·동일 출처**로 제한됩니다. 다른 기기에서 초대에 참여하려면 배포용 백엔드와 공유 가능한 도메인을 연결해야 합니다. 이메일 확인·비밀번호 재설정, 메일/SMS 발송, 운영용 DB·백업·다중 서버, 30분 자동 수집·경보, 자유 문장 번역·역번역은 후속 범위입니다.

`VITE_API_BASE_URL`로 관측·채팅·계정·작업 API 주소를 함께 교체할 수 있습니다. 별도 서버는 쿠키 인증과 브라우저 출처를 허용하거나 같은 출처 프록시로 제공해야 합니다. 계약은 [관측·채팅 API](docs/design/chat-api.md), [계정·작업 API](docs/design/workspace-api.md)에 정리했습니다.
