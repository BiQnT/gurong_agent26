'디지털 트윈 데이터를 최소 1개 이상 실제 호출·활용'이 필수 요건이고, 심사 배점
25점이 '실현 가능성'이다. **아이디어를 확정하기 전에 호출되는 API를 먼저 확보한다.**

## 조사 우선순위

1. E-UM 포털에 Open API 문서가 있는지, 키 발급이 되는지 — **가장 먼저**
2. 주최 측(권소현, ikwon@postech.ac.kr)에 참가자 제공 데이터 범위와 제공 시점 문의
3. 공공데이터포털에서 구룡포/포항 관련 대체 데이터 (기상, 해양, 조위, 파고,
   수질, 대기질, 수산물 위판, 관광)
