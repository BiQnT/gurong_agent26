## 읽는 법

- **판정 O + 건수 0** — 응답은 오는데 데이터가 비었다. 장비 미설치이거나 아직 수집 전이다.
  아이디어의 근거로 쓰기 전에 반드시 확인할 것.
- **판정 X** — 파라미터가 더 필요하거나 권한 밖이다. `raw/<API_ID>.json` 의 응답을 보고
  카탈로그 스펙과 대조한다.
- 건수는 응답 안에서 가장 긴 리스트의 길이다. 정확한 장비 수는 원본 JSON 으로 확인할 것.
