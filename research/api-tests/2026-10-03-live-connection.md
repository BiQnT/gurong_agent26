# 2026-10-03 · 로컬 연결 서버의 외부 API 확인

확인일: **2026-10-03**. 이번 개발 세션에서 실행한 실제 요청 결과와 저장된 응답 자료의 상태를 기록한다. 인증키, 인증 헤더, 키가 포함된 요청 URL은 기록하지 않는다. 과거 호출 기록은 수정하지 않는다.

## E-UM 직접 호출

| API                                | 요청 경로                              | HTTP 결과 | 응답 코드·내용                             |
| ---------------------------------- | -------------------------------------- | --------- | ------------------------------------------ |
| `INT_S01_001` · 장비 목록          | `GET /dpg/atmosphere/devices`          | 401       | `40102` · `유효하지 않은 이용자 서비스 키` |
| `INT_S01_003` · 대기환경 일괄 조회 | `GET /dpg/atmosphere/devices/realtime` | 401       | `40102` · `유효하지 않은 이용자 서비스 키` |
| `INT_S01_004` · 대기환경 단건 조회 | `GET /dpg/atmosphere/device/realtime`  | 401       | `40102` · `유효하지 않은 이용자 서비스 키` |

원천 서버는 `https://genix.pohang-eum.kr`이다. 위 요청에는 서버의 인증값을 사용했으며, 확인 시점에 세 경로 모두 인증이 거절됐다. 응답의 비밀정보 없는 부분만 정규화한 기록은 다음과 같다. 원천 응답 전체의 스키마를 뜻하지 않는다.

```json
{
  "upstreamHttpStatus": 401,
  "upstreamCode": 40102,
  "message": "유효하지 않은 이용자 서비스 키"
}
```

따라서 이번 확인에서는 새로운 관측값을 확보하지 못했다. 현재 관측을 제공하려면 E-UM에서 수락하는 서비스 키로 다시 호출해야 한다.

## OpenAI 직접 호출

`POST /v1/responses`에 `gpt-4.1-mini`와 짧은 확인 입력을 전달했다. 결과는 **HTTP 200**, 응답 상태는 **`completed`**였다. 이는 해당 모델의 실제 호출이 가능함을 확인한 결과이며, 건조 판정의 정확성이나 번역 검증을 입증하지 않는다. 입력·출력 전문과 인증값은 이 기록에 저장하지 않는다.

## 보관된 실제 E-UM 자료

저장소에 있던 다음 두 파일에서 `response.data`만 읽어 확인했다. 요청 URL이나 파라미터를 브라우저로 전달하지 않는다.

| 파일                                      | 확인된 자료  |
| ----------------------------------------- | ------------ |
| `research/api-tests/raw/INT_S01_001.json` | 장비 24개    |
| `research/api-tests/raw/INT_S01_003.json` | 관측 행 23개 |

관측 행의 원문 `logDateTime`은 **2026-08-06 00:57:32 ~ 2026-08-06 12:00:33** 범위다. 원문 문자열에 시간대가 없으므로 정규화할 때 적용한 시간대와 이 한계를 함께 표시해야 한다. 자료의 가장 최근 관측일은 **2026-08-06**이며 현재 관측이 아니다.

로컬 연결 서버는 실시간 요청이 실패하면 이 자료를 `status: "archived"`로 구분해 표시한다. 보관 자료의 유효한 행도 현재 상태인 `current`로 바꾸지 않고 `stale`로 전달하며, 누락된 관측값을 생성하지 않는다. 과거 관측을 현재 배치의 관측 기록이나 지금의 건조 판단에 사용하지 않는다.

정규화와 폴백 구현은 [server/eum.ts](../../server/eum.ts), 브라우저 응답 계약은 [src/lib/live.ts](../../src/lib/live.ts)에 있다. 앱의 요청 경로와 서버 연결 방법은 [API 연결 계약](../../docs/design/chat-api.md)을 참고한다.

## 앱 연결 경로 확인

`http://127.0.0.1:3000`의 `/api/health`, `/api/observations`, `/api/chat`을 실제 호출해 모두 HTTP 200을 확인했다. 관측 응답은 장비 24개, `status: archived`, 원천 HTTP 401 경고를 포함했다. 채팅 응답은 `provider: openai`였고, 선택 관측 시각 `2026-08-06T03:00:33.000Z`와 `status: stale`을 유지했다. 모델은 시간대 가정과 과거 자료의 한계를 설명했으며 건조 등급은 반환되지 않았다.

Safari UI 제어는 도구가 `Computer Use was not approved to use Safari`를 반환해 실행하지 못했다. HTTP 연결 확인과 실제 Safari 화면 검증은 구분한다.
