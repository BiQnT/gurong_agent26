# 2026-10-04 · 교체한 E-UM 키 연결 확인

사용자가 제공한 URL 인코딩 형태의 키를 서버 전용 환경 파일에 적용했다. 실제 요청에는 퍼센트 인코딩을 한 번 해제한 값을 `serviceKey`로 전달했다. 비밀키와 키가 포함된 URL은 이 기록에 저장하지 않는다.

| API | 요청 경로 | 실제 결과 |
| --- | --- | --- |
| `INT_S01_001` | `GET /dpg/atmosphere/devices` | HTTP 401 · `40104` · 요청한 API에 대한 권한 없음 |
| `INT_S01_003` | `GET /dpg/atmosphere/devices/realtime` | HTTP 200 · `status: success` · 23행 |
| `INT_S01_004` | `GET /dpg/atmosphere/device/realtime` (`id=1`) | HTTP 200 · `status: success` |

일괄 응답에는 새 관측과 오래된 관측이 섞여 있다. 최초 확인한 원문 관측 시각 범위는 `2026-06-16 10:57:15`부터 `2026-10-04 13:52:34`까지다. 원문에는 시간대가 없으며 앱은 `+09:00`을 가정했다는 한계를 표시한다.

단건 조회 응답에서 비밀정보 없는 측정 필드만 추린 실제 샘플:

```json
{
  "devId": 1,
  "logDateTime": "2026-10-04 13:51:33",
  "temp": 23.1,
  "humi": 54.5,
  "winsp": 1.14
}
```

앱의 `/api/observations`도 HTTP 200, `status: ok`를 확인했다. 보관된 장비 정보 24개에 실시간 API의 관측을 연결한 결과, 확인 시점 기준 최근 관측 18개·과거 관측 5개·결측 1개였다. 선택된 북방파제 3의 원문 측정 시각은 `2026-10-04 13:54:41`, 기온 28.6°C·습도 54%·풍속 3.68m/s였다. 이 수치는 테스트 당시의 값이며 화면에는 매 요청의 실제 응답을 사용한다.

필요한 추가 권한은 **관측기 목록 조회 `INT_S01_001`**이다. 권한이 승인되면 같은 코드 경로가 API의 장비 정보를 우선 사용한다. 목록의 권한 부족을 이유로 성공한 실시간 측정까지 과거 측정값으로 대체하지 않는다.

후속 `/api/chat` 요청도 HTTP 200, `provider: openai`를 확인했다. 관측기 `1`의 `2026-10-04 13:55:33` 측정값(기온 22.6°C)이 전달됐고, 모델은 해당 측정 시각과 시간대 가정을 설명했다. 환경 적합 등급은 생성하지 않았다. 전체 테스트 17개, 프론트·서버 타입 검사, 빌드와 포맷 검사가 통과했다.

## 14:01 KST · 관측기 목록 권한 승인 후 재확인

사용자의 권한 승인 후 `2026-10-04T05:01:00.877Z`에 같은 키로 재호출했다.

| API | 승인 후 실제 결과 |
| --- | --- |
| `INT_S01_001` · 관측기 목록 | HTTP 200 · `status: success` · 24개 |
| `INT_S01_003` · 일괄 관측 | HTTP 200 · `status: success` · 23행 |
| `INT_S01_004` · 단건 관측 (`id=1`) | HTTP 200 · `status: success` |

관측기 `1`의 이름은 구룡포행정복지센터 남서측, 좌표는 `35.980946, 129.540324`로 API에서 확인했다. 단건 관측은 원문 시각 `2026-10-04 14:00:33`, 기온 22.7°C·습도 57%·풍속 0.95m/s였다. 일괄 응답의 가장 최근 원문 관측 시각은 `2026-10-04 14:00:58`이었다. 이전 권한 오류는 해소됐으며 장비 정보도 API에서 직접 확보할 수 있다.

14:01:10 KST에 별도 검증 에이전트가 로컬 `/api/observations`를 조회했다. HTTP 200과 `readLiveSnapshot` 검증 통과를 확인했으며, `status: ok`와 최근 관측 18개·과거 관측 5개·무효/결측 1개를 반환했다. 보관된 장비 정보를 사용한다는 경고는 없었다. 확인한 응답은 조회 시점 25초 전에 생성돼 서버의 30초 캐시 범위였다.
