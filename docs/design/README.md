# 설계 문서

**"현재 이렇게 되어 있다"만 적는다.** "왜 그렇게 정했나"는 [결정 기록](../decisions/)에.

서술형 문서는 낡기 쉬우므로 최소로 유지한다:

- 코드를 보면 알 수 있는 것은 적지 않는다
- 각 파일 맨 위에 **마지막 확인일**을 적는다
- 코드를 바꾸는 PR에서 이 폴더가 틀려지면 **같은 PR에서** 고친다
