# 해풍 IR 소개 영상 계획

작성 2026-10-09 · 대상: 본선 발표(IR) 맨 앞에 트는 영상 · 도구: Remotion (React 로 만드는 영상)

## 0. 한 줄

"구룡포 덕장 운영자가 오늘 널어도 되는지 묻고, 해풍이 실제 관측으로 답하고, 근로자에게 그 언어로 전한다"를 75초 안에 보여 준다.

## 1. 참고 영상과 톤

- 참고: *Introducing Claude Design by Anthropic Labs*. 영상 파일은 찾지 못해 출시 글의 흐름(무엇인지 → 어떻게 쓰는지 → 시작하기)과 Anthropic 출시 영상의 일반적인 결을 따른다.
- 결: 밝은 미색 배경, 큰 세리프 제목 한 줄, 실제 제품 화면을 천천히 보여 주는 장면, 짧은 자막, 과장 없는 움직임(느린 확대·밀기·페이드), 화면마다 시선이 갈 곳 하나.
- 색은 우리 제품을 따른다: 흰색·검정·중성 회색 + 등급 색(적합 초록 `#3d8c5c`, 주의 노랑 `#d9a23f`, 부적합 빨강 `#c4513b`). 바다 느낌은 옅은 물결선 하나로만.
- 글꼴: 제목 Noto Serif KR, 본문 Noto Sans KR (Google Fonts, 한국어 지원). 대체됨 (→ 7절, 3판)
- 소리: 1차는 무음 + 자막. 내레이션·음악은 평가 뒤 정한다 (저작권 확인 필요).

## 3. 화면 자료

- **배포된 버전과 같은 코드로 찍는다.** prod DB 에 시연 자료를 넣으면 실제 자료에 섞이므로, 배포한 main 커밋을 로컬에서 따로 만든 DB 로 띄우고 실제 E-UM·기상청·claude 를 써서 찍는다 (화면·답·카드는 배포본과 같다).
- 시연 자료: 운영자 계정, 덕장 "구룡포 시연 덕장", 진행 중인 배치(꽁치 500마리), 베트남어 근로자 1명, 승인한 작업 안내와 근로자 질문·운영자 답변.
- 찍는 화면 (Playwright, 데스크톱 1440×900 · 폰 390×844, 2배 해상도):
  1. 채팅: "오늘 우리 덕장 널어도 괜찮아?" 답 (현재 건조 환경 카드)
  2. 채팅: "내일 널어도 돼?" 답 (예보 카드)
  3. 채팅: "작년 12월 구룡포 건조 조건 분석해줘" 답 (기간 요약 카드)
  4. 건조 기록 화면
  5. 작업 안내 승인 미리보기 (한국어·베트남어)
  6. 근로자 폰 화면 (베트남어, 질문과 답변)
- 실제 답과 수치를 그대로 쓴다. 영상 안에서 숫자를 지어 넣지 않는다.

## 4. 만드는 법

- 위치: `media/ir-intro/` (앱과 별도 Remotion 프로젝트, 앱 빌드·테스트와 분리). 화면 자료는 `media/ir-intro/public/shots/`. 실제로 만든 장면 길이·문구는 `src/` 가 정본이다.
- 장면마다 컴포넌트 하나, `TransitionSeries` 로 잇고 장면 사이는 0.5초 페이드.
- 움직임: `interpolate` + `Easing.bezier(0.16, 1, 0.3, 1)`. 화면은 천천히 확대(1.0 → 1.04), 카드는 아래에서 올라오며 나타남, 타이핑은 글자 수로 끊어 보임.
- 확인: Remotion Studio 로 미리 보기, 평가용 MP4 를 한 번 렌더(`out/haepung-intro.mp4`).

## 5. 평가 받을 것

## 6. 2판 (2026-10-09, 1판 평가 반영)

1판 평가: 부수적인 글자(팀·대회 이름, 자료 출처)가 많고, 운영자·근로자가 주고받을 때 무엇이 바뀌는지 안 보이고, 실제 앱이 돌아가는 느낌이 약하고, 소리가 없고, 글자가 PPT 처럼 뜬다.

| 바꾼 것 | 어떻게 |
| --- | --- |
| 부수 글자 | 팀·대회·자료 출처 문구를 모두 뺐다. 남은 글은 장 제목과 운영자·근로자 표시뿐 |
| 앱 전체 먼저 | 로고 뒤에 앱 전체 화면이 기울어진 채 올라와 펴지고, 왼쪽 메뉴의 네 기능을 박자마다 짚는다 |
| 실제로 돌아가는 화면 | 상태마다 실제 화면을 새로 찍고(27장), 커서 이동·클릭, 입력칸 타이핑(다 쓴 화면에서 글자를 한 자씩 드러냄), 보내기, 생각 중, 답, 다음 화면 순서로 바꾼다. 카메라가 지금 바뀌는 곳으로 다가간다 |
| 주고받기 | 운영자 데스크톱과 근로자 휴대폰을 나란히 두고, 받는 쪽 화면이 커진다. 안내·질문·답변이 칩이 되어 두 화면 사이를 날아가고, 안내 칩은 날아가는 도중 한국어에서 베트남어로 바뀐다. 도착한 곳을 비춘다 |
| 소리 | 음악(100BPM, D장조, 패드·아르페지오·부드러운 킥)과 효과음(클릭·타이핑·보내기·도착)을 `scripts/make-audio.mjs` 로 직접 합성했다. 외부 음원이 없어 저작권 문제가 없다 |
| 글자 연출 | 어두운 화면에 바람 줄기, 낱말이 흐림에서 또렷해지며 떠오르는 큰 세리프 글씨. 장 제목은 흐려진 앱 화면 위에 떴다가 흩어지며 화면이 다시 또렷해진다 |

순서 (78초, 음악 박자 격자에 맞춤): 여는 말 0~8초 → 문제 세 가지 8~14.4 → 해풍과 앱 전체 14.4~24 → 말하면 기록 24~33.6 → 지금 판단 33.6~42 → 운영자와 근로자 42~57.6 → 예보와 과거 분석 57.6~67.2 → 한 줄 정리 67.2~72 → 맺음 72~78.

2판 평가 (2026-10-09): 음악·순서는 좋고, 속도만 0.8배로. 장면 안 시각은 그대로 두고 `src/timeline.ts` 의 `SPEED` 로 영상 전체를 늦췄고(78초 → 97.5초), 음악도 같은 비율(100BPM → 80BPM)로 다시 합성해 박자를 맞췄다.
0.8배 평가 (2026-10-09): 너무 느려 0.9배로 다시 맞췄다 (약 86.7초, 음악 90BPM).

## 7. 3판 (2026-10-10, 글꼴과 음악)

받은 평가: 한국어 글꼴을 하나로 통일할 것(앱 화면은 빼고), 음악이 수동적이고 정적이라 애플(아이폰) 광고 느낌으로 바꿀 것. 장면 순서와 시각은 그대로 둔다.

| 바꾼 것 | 어떻게 |
| --- | --- |
| 글꼴 | 영상이 직접 그리는 글자(큰 글씨, 장 제목, 로고 옆 이름과 한 줄 소개, 맺음 문구, 운영자·근로자 표시, 칩)를 Apple SD 산돌고딕 Neo 하나로. 궁서와 비교해 골랐다(궁서는 맥에 굵기가 하나뿐이라 굵은 제목이 억지로 두꺼워진다). 산돌고딕에 베트남어 성조 글자가 없어 영문·숫자·베트남어는 SF. 맥 시스템 글꼴이라 렌더는 맥에서 한다. 앱 화면(찍은 이미지)과 로고 그림은 그대로 |
| 음악 | 135BPM 인디 일렉트로 팝: 아날로그 신스 베이스, 옛 드럼머신 킥·스네어, 탬버린, 뮤트 기타 커팅, 숨 섞인 낮은 목소리 화음, 유리 같은 벨. 화음 하나(실제 약 5.3초)가 3마디라 장면 시각을 바꾸지 않아도 경계가 박 위에 온다 (운영자와 근로자 장면만 마디 중간) |
| 강약 | 화면에서 일이 일어나는 순간에 맞춰 친다: 첫 글자, “널어도 될까요?”, 문제 세 줄(갈수록 세게), 로고, 메뉴 네 번 짚기(한 음씩 올라감), 장 제목(직전 한 박 멈춤), 칩 도착(벨). 앱이 타이핑하고 답이 오는 동안은 베이스·하이햇·기타만 남기고 물러난다. 운영자와 근로자 장면은 킥을 빼고 가볍게, 예보와 과거 분석이 가장 꽉 차고, 한 줄 정리에서 비운 뒤 맺음에서 처음으로 으뜸화음(D)으로 끝난다 |
| 음량 | 음악 전체 음량은 2판 음악과 거의 같다 (−17.3 LUFS, 2판 −16.9). 효과음과의 비율은 그대로 |

음악을 정한 과정 (견본은 모두 직접 합성):

1. 1차: B안 90BPM 그루브, C안 135BPM 업비트(신스 화음, 네 박 킥, 펌핑 베이스). C안 평가: 업비트는 괜찮지만 너무 튀고 강약과 애플다운 느낌이 없다.
2. 방향 견본(앞 37초): 1 다듬은 업비트(피아노·둥근 베이스), 2 미니멀(스냅·깊은 저음), 3 사람 소리 업비트(발 구르기·손뼉·마림바). 모두 화면 사건에 맞춘 강약을 넣었다. 평가: 1과 3의 중간, 글자에 맞춰 치는 것은 좋다, 그런데 애플은 이런 악기를 잘 안 쓴다.
3. 악기를 바꾼 견본: 4 인디 일렉트로 팝, 5 미니멀 시퀀스(피치카토·현악). 근거는 애플 사운드 디자인이 손에 잡히는 듯한 실제 소리를 고른다는 점([Twenty Thousand Hertz](https://20k.org/episodes/the-sound-of-apple-2)), 최근 아이폰 발표·광고 곡이 인디 일렉트로·신스팝이라는 점([Galaxus](https://www.galaxus.de/en/page/apples-marketing-in-11-songs-39925), [The Drum](https://www.thedrum.com/news/2024/09/10/the-weeknd-s-latest-music-video-shot-entirely-iphone-16-pro)). 평가: 4로, 신스 베이스만 줄이기. 베이스를 견본보다 약 5dB 낮춰 전체 길이로 이었다.
4. 전체 길이 평가: 괜찮지만 높은 음으로 튕기는 목소리 조각 훅이 유치하고 애플 같은 무게감이 없다. 멜로디 자리만 바꾼 세 가지(멜로디 빼기, 한 옥타브 낮고 긴 신스 선율, 숨 섞인 낮은 목소리 화음)를 비교해 목소리 화음으로 정했다.
