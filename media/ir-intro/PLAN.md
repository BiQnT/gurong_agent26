# 해풍 IR 소개 영상 계획

작성 2026-10-09 · 대상: 본선 발표(IR) 맨 앞에 트는 영상 · 도구: Remotion (React 로 만드는 영상)

## 0. 한 줄

"구룡포 덕장 운영자가 오늘 널어도 되는지 묻고, 해풍이 실제 관측으로 답하고, 근로자에게 그 언어로 전한다"를 75초 안에 보여 준다.

## 1. 참고 영상과 톤

- 참고: *Introducing Claude Design by Anthropic Labs*. 영상 파일은 찾지 못해 출시 글의 흐름(무엇인지 → 어떻게 쓰는지 → 시작하기)과 Anthropic 출시 영상의 일반적인 결을 따른다.
- 결: 밝은 미색 배경, 큰 세리프 제목 한 줄, 실제 제품 화면을 천천히 보여 주는 장면, 짧은 자막, 과장 없는 움직임(느린 확대·밀기·페이드), 화면마다 시선이 갈 곳 하나.
- 색은 우리 제품을 따른다: 흰색·검정·중성 회색 + 등급 색(적합 초록 `#3d8c5c`, 주의 노랑 `#d9a23f`, 부적합 빨강 `#c4513b`). 바다 느낌은 옅은 물결선 하나로만.
- 글꼴: 제목 Noto Serif KR, 본문 Noto Sans KR (Google Fonts, 한국어 지원).
- 소리: 1차는 무음 + 자막. 내레이션·음악은 평가 뒤 정한다 (저작권 확인 필요).

## 3. 화면 자료

- **배포된 버전과 같은 코드로 찍는다.** prod DB 에 시연 자료를 넣으면 실제 자료에 섞이므로, 배포한 main 커밋을 로컬에서 따로 만든 DB 로 띄우고 실제 E-UM·기상청·claude 를 써서 찍는다 (화면·답·카드는 배포본과 같다).
- 시연 자료: 운영자 계정, 덕장 "구룡포 시연 덕장", 진행 중인 배치(꽁치 500마리), 베트남어 근로자 1명, 승인한 작업 안내와 근로자 질문·운영자 답변.
- 찍는 화면 (Playwright, 데스크톱 1440×900 · 폰 390×844, 2배 해상도):
  1. 채팅: "오늘 우리 덕장 널어도 괜찮아?" 답 (현재 건조 환경 카드)
  2. 채팅: "내일 널어도 돼?" 답 (예보 카드)
  3. 채팅: "작년 12월 구룡포 건조 조건 분석해줘" 답 (기간 요약 카드)
  4. 건조 기록 화면
  5. 작업 안내 승인 미리보기 (한국어·베트남어)
  6. 근로자 폰 화면 (베트남어, 질문과 답변)
- 실제 답과 수치를 그대로 쓴다. 영상 안에서 숫자를 지어 넣지 않는다.

## 4. 만드는 법

- 위치: `media/ir-intro/` (앱과 별도 Remotion 프로젝트, 앱 빌드·테스트와 분리). 화면 자료는 `media/ir-intro/public/shots/`. 실제로 만든 장면 길이·문구는 `src/` 가 정본이다.
- 장면마다 컴포넌트 하나, `TransitionSeries` 로 잇고 장면 사이는 0.5초 페이드.
- 움직임: `interpolate` + `Easing.bezier(0.16, 1, 0.3, 1)`. 화면은 천천히 확대(1.0 → 1.04), 카드는 아래에서 올라오며 나타남, 타이핑은 글자 수로 끊어 보임.
- 확인: Remotion Studio 로 미리 보기, 평가용 MP4 를 한 번 렌더(`out/haepung-intro.mp4`).
