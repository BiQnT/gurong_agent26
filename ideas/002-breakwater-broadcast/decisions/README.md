# 이 아이디어의 결정 기록

`docs/decisions/`는 **프로젝트 전역** 결정의 정본이다. 여기는 **이 아이디어 안에서만
유효한** 결정을 쌓는 곳이다.

둘을 나누는 이유는 규칙 두 개가 서로 부딪히기 때문이다.

- `ideas/README.md`: "한 브랜치는 자기 아이디어 폴더만 건드린다"
- `CLAUDE.md`: "결정과 그 이유는 `docs/decisions/`가 정본"

아이디어 브랜치에서 `docs/decisions/`를 고치면 앞의 규칙을 어기고, 결정을 아무 데도
안 적으면 뒤의 규칙을 어긴다. 그래서 **아이디어 범위 결정은 여기 쌓고, 이 아이디어가
확정돼 `main`에 머지될 때 프로젝트 전역에 해당하는 것만 `docs/decisions/`로 승격**한다.

승격할 때는 새 번호를 받고, 여기 원본에 `승격됨 (→ docs/decisions/NNNN)`을 남긴다.
기록은 고치지 않는다 — 결정이 뒤집히면 새 문서를 쓰고 옛 것에 `대체됨 (→ NNNN)`을 적는다.

양식은 [`docs/decisions/_template.md`](../../../docs/decisions/_template.md)를 그대로 쓴다.
